# Skill Seekers 平台适配器对比分析

## 概述

Skill Seekers 使用**策略模式**实现多平台支持，通过 `SkillAdaptor` 抽象基类定义统一接口，每个平台实现自己的适配器。

```
adaptors/
├── base.py          # 抽象基类（SkillAdaptor）
├── claude.py        # Claude AI 适配器
├── gemini.py        # Google Gemini 适配器
├── openai.py        # OpenAI ChatGPT 适配器
└── markdown.py      # 通用 Markdown 适配器
```

---

## 一、核心差异对比表

| 特性 | Claude AI | Google Gemini | OpenAI ChatGPT | Generic Markdown |
|-----|-----------|---------------|----------------|------------------|
| **平台标识** | `claude` | `gemini` | `openai` | `markdown` |
| **SKILL.md 格式** | YAML frontmatter + Markdown | 纯 Markdown（无 frontmatter） | 纯文本指令（Assistant instructions） | 纯 Markdown |
| **打包格式** | `.zip` | `.tar.gz` | `.zip` | `.zip` |
| **主文件名** | `SKILL.md` | `system_instructions.md` | `assistant_instructions.txt` | `README.md` |
| **引用文件目录** | `references/*.md` | `references/*.md` | `vector_store_files/*.md` | `references/*.md` |
| **元数据文件** | 无 | `gemini_metadata.json` | `openai_metadata.json` | `metadata.json` |
| **上传端点** | `api.anthropic.com/v1/skills` | Google Files API | OpenAI Assistants API | 不支持上传 |
| **API Key 前缀** | `sk-ant-` | `AIza` | `sk-` | N/A |
| **环境变量** | `ANTHROPIC_API_KEY` | `GOOGLE_API_KEY` | `OPENAI_API_KEY` | 无 |
| **AI 增强模型** | Claude Sonnet 4 | Gemini 2.0 Flash | GPT-4o | 不支持 |
| **AI 增强支持** | ✅ 支持 | ✅ 支持 | ✅ 支持 | ❌ 不支持 |

## 二、SKILL.md 格式差异

### 2.1 Claude AI - YAML Frontmatter

```markdown
---
name: react
description: React documentation skill for building UIs
version: 1.0.0
---

# React Documentation Skill

React documentation, including API references...

## When to use this skill

Use this skill when the user asks about React...
```

**特点**：
- 使用 YAML frontmatter（`---` 包裹）
- Frontmatter 包含 name, description, version
- 后续是完整的 Markdown 内容
- 符合 Claude Skills 标准格式

### 2.2 Google Gemini - 纯 Markdown

```markdown
# React Documentation

**Description:** React documentation skill for building UIs

## Quick Reference

...

## Table of Contents

...
```

**特点**：
- 不使用 frontmatter
- 纯 Markdown 格式
- 描述使用 **Description:** 加粗显示
- 适合 Gemini 的 grounding 机制

### 2.3 OpenAI ChatGPT - Assistant 指令

```text
You are an expert assistant for React.

React documentation skill for building UIs

## Your Knowledge Base

You have access to comprehensive documentation files about React...

## How to Assist Users

When users ask questions about React:
1. Search the knowledge files - Use file_search to find relevant information
2. Provide code examples - Include practical, working code snippets
...

Always prioritize accuracy by consulting the attached documentation files.
```

**特点**：
- 纯文本指令（非 Markdown 格式）
- 以 "You are an expert..." 开头
- 强调使用 `file_search` 工具
- 更像是给 AI 助手的行为指南

### 2.4 Generic Markdown - 通用 Markdown

```markdown
# React Documentation

React documentation skill for building UIs

## Table of Contents

...

## Quick Reference

...

---

*Documentation generated by Skill Seekers*
```

**特点**：
- 纯净的 Markdown 格式
- 没有平台特定的格式要求
- 可用于任何支持 Markdown 的系统

## 四、上传机制差异

### 4.1 Claude AI 上传

**API 端点**: `https://api.anthropic.com/v1/skills`

**上传方式**:
```python
files = {
    'files[]': (package_name, zip_data, 'application/zip')
}
headers = {
    "x-api-key": api_key,
    "anthropic-version": "2023-06-01",
    "anthropic-beta": "skills-2025-10-02"
}
response = requests.post(api_url, headers=headers, files=files)
```

**返回结果**:
- `skill_id`: Claude skill ID
- `url`: `https://claude.ai/skills`

### 4.2 Google Gemini 上传

**API 端点**: Google Files API (`genai.upload_file`)

**上传方式**:
```python
import google.generativeai as genai

genai.configure(api_key=api_key)

# 上传主文件
uploaded_file = genai.upload_file(
    path=str(main_file),
    display_name=f"{skill_name}_instructions"
)

# 上传引用文件
for ref_file in refs_dir.glob("*.md"):
    ref_uploaded = genai.upload_file(
        path=str(ref_file),
        display_name=f"{skill_name}_{ref_file.stem}"
    )
```

**返回结果**:
- `skill_id`: File ID
- `url`: `https://aistudio.google.com/app/files/{file_id}`

### 4.3 OpenAI ChatGPT 上传

**API 端点**: OpenAI Assistants API

**上传方式**:
```python
from openai import OpenAI

client = OpenAI(api_key=api_key)

# 1. 创建 Vector Store
vector_store = client.beta.vector_stores.create(
    name=f"{skill_name} Documentation"
)

# 2. 上传文件到 Vector Store
file_ids = []
for ref_file in vector_files_dir.glob("*.md"):
    uploaded_file = client.files.create(
        file=f, purpose='assistants'
    )
    file_ids.append(uploaded_file.id)

# 3. 关联文件到 Vector Store
client.beta.vector_stores.files.create_batch(
    vector_store_id=vector_store.id,
    file_ids=file_ids
)

# 4. 创建 Assistant
assistant = client.beta.assistants.create(
    name=skill_name,
    instructions=instructions,
    model="gpt-4o",
    tools=[{"type": "file_search"}],
    tool_resources={
        "file_search": {
            "vector_store_ids": [vector_store.id]
        }
    }
)
```

**返回结果**:
- `skill_id`: Assistant ID
- `url`: `https://platform.openai.com/assistants/{assistant_id}`

### 4.4 Generic Markdown 上传

**不支持上传** - 返回本地路径供用户手动使用

```python
return {
    'success': False,
    'skill_id': None,
    'url': str(package_path.absolute()),
    'message': 'Generic markdown export does not support automatic upload.'
}
```

## 五、AI 增强 (Enhancement) 差异

### 5.1 Claude AI 增强

**模型**: `claude-sonnet-4-20250514`
**API**: Anthropic Messages API

```python
message = client.messages.create(
    model="claude-sonnet-4-20250514",
    max_tokens=4096,
    temperature=0.3,
    messages=[{"role": "user", "content": prompt}]
)

enhanced_content = message.content[0].text
```

**Prompt 特点**:
- 强调保留 YAML frontmatter
- 要求提取真实代码示例
- 生成 "When to Use This Skill" section

### 5.2 Google Gemini 增强

**模型**: `gemini-2.0-flash-exp`
**API**: Google Generative AI

```python
model = genai.GenerativeModel('gemini-2.0-flash-exp')
response = model.generate_content(prompt)
enhanced_content = response.text
```

**Prompt 特点**:
- 强调不使用 YAML frontmatter
- 生成纯 Markdown 格式
- 适合 Gemini grounding

### 5.3 OpenAI ChatGPT 增强

**模型**: `gpt-4o`
**API**: OpenAI Chat Completions

```python
response = client.chat.completions.create(
    model="gpt-4o",
    messages=[
        {
            "role": "system",
            "content": "You are an expert technical writer creating Assistant instructions for OpenAI ChatGPT."
        },
        {"role": "user", "content": prompt}
    ],
    temperature=0.3,
    max_tokens=4096
)

enhanced_content = response.choices[0].message.content
```

**Prompt 特点**:
- 强调不使用 YAML frontmatter
- 生成 Assistant 指令格式
- 强调 file_search 使用

### 5.4 Generic Markdown 增强

**不支持 AI 增强**

```python
def enhance(self, skill_dir: Path, api_key: str) -> bool:
    print("❌ Generic markdown export does not support AI enhancement")
    return False
```

## 六、代码实现共性与差异

### 6.1 共性（相同的实现）

所有适配器都实现了相同的辅助方法：

```python
def _read_reference_files(self, references_dir: Path, max_chars: int = 200000)
    """读取引用文件，限制最大字符数"""

def _build_enhancement_prompt(self, skill_name: str, references: Dict, current_skill_md: str)
    """构建增强 Prompt"""
```

**相同的增强流程**:
1. 读取 references 目录
2. 读取当前 SKILL.md
3. 构建 enhancement prompt
4. 调用 LLM API
5. 备份原文件
6. 保存增强后的内容

### 6.2 差异（平台特定实现）

#### format_skill_md() - SKILL.md 格式

| 平台 | Frontmatter | 主要内容格式 |
|-----|------------|------------|
| Claude | YAML (---...---) | Markdown |
| Gemini | 无 | Markdown |
| OpenAI | 无 | 纯文本指令 |
| Markdown | 无 | Markdown |

#### package() - 打包格式

| 平台 | 压缩格式 | 主文件名 | 特殊文件 |
|-----|---------|---------|---------|
| Claude | ZIP | SKILL.md | 无 |
| Gemini | tar.gz | system_instructions.md | gemini_metadata.json |
| OpenAI | ZIP | assistant_instructions.txt | openai_metadata.json |
| Markdown | ZIP | README.md + DOCUMENTATION.md | metadata.json |

#### upload() - 上传机制

| 平台 | 依赖库 | 上传对象 | 额外操作 |
|-----|-------|---------|---------|
| Claude | requests | ZIP 文件 | 直接上传 |
| Gemini | google-generativeai | 多个文件 | 逐文件上传 |
| OpenAI | openai | Vector Store + Assistant | 创建 Vector Store、上传文件、创建 Assistant |
| Markdown | 无 | 无 | 返回本地路径 |

## 七、使用场景对比

### 7.1 Claude AI 适配器

**最佳场景**:
- 使用 Claude Code 或 Claude Web
- 需要 Claude 原生 Skills 功能
- 想要最好的 Claude 集成体验

**特点**:
- 官方 Skills 格式
- 完整的 YAML 元数据
- 支持 scripts 和 assets

### 7.2 Google Gemini 适配器

**最佳场景**:
- 使用 Google AI Studio
- 需要 Gemini grounding 功能
- 使用 Gemini API 开发

**特点**:
- Files API 集成
- tar.gz 压缩（Linux 风格）
- 适合 Gemini 2.0 Flash

### 7.3 OpenAI ChatGPT 适配器

**最佳场景**:
- 使用 ChatGPT Assistants API
- 需要 Vector Store 搜索
- 构建自定义 GPT

**特点**:
- Assistants API 集成
- Vector Store + file_search
- 适合 GPT-4o

### 7.4 Generic Markdown 适配器

**最佳场景**:
- 不依赖特定平台
- 用于文档归档
- 需要人工阅读的文档
- 用于其他 LLM 或工具

**特点**:
- 通用性最强
- 无平台依赖
- 包含合并文档（DOCUMENTATION.md）

## 九、工厂模式实现

所有适配器通过工厂函数获取：

```python
# adaptors/__init__.py
from .claude import ClaudeAdaptor
from .gemini import GeminiAdaptor
from .openai import OpenAIAdaptor
from .markdown import MarkdownAdaptor

def get_adaptor(target: str) -> SkillAdaptor:
    """Get platform-specific adaptor"""
    adaptors = {
        'claude': ClaudeAdaptor,
        'gemini': GeminiAdaptor,
        'openai': OpenAIAdaptor,
        'markdown': MarkdownAdaptor
    }

    if target not in adaptors:
        raise ValueError(f"Unknown target: {target}")

    return adaptors[target]()
```

**使用方式**:
```python
from skill_seekers.cli.adaptors import get_adaptor

# 获取适配器
adaptor = get_adaptor('claude')  # 或 'gemini', 'openai', 'markdown'

# 打包
adaptor.package(skill_dir, output_path)

# 上传（如果支持）
if adaptor.supports_enhancement():
    adaptor.upload(package_path, api_key)

# 增强（如果支持）
if adaptor.supports_enhancement():
    adaptor.enhance(skill_dir, api_key)
```

## 十、关键设计模式

### 10.1 策略模式 (Strategy Pattern)

- **抽象策略**: `SkillAdaptor` (base.py)
- **具体策略**: `ClaudeAdaptor`, `GeminiAdaptor`, `OpenAIAdaptor`, `MarkdownAdaptor`
- **上下文**: 通过 `get_adaptor()` 工厂函数选择策略

**优点**:
- 单一代码库支持多平台
- 易于添加新平台
- 平台特定逻辑隔离
- 可独立测试每个平台

### 10.2 模板方法模式 (Template Method)

基类提供辅助方法供子类使用：

```python
# 基类提供的模板方法
class SkillAdaptor(ABC):
    def _read_existing_content(self, skill_dir: Path) -> str:
        """读取现有内容（去除 frontmatter）"""

    def _extract_quick_reference(self, skill_dir: Path) -> str:
        """提取快速参考"""

    def _generate_toc(self, skill_dir: Path) -> str:
        """生成目录"""
```

所有子类复用这些方法，保证一致性。

## 十一、总结与推荐

### 各平台适配器的核心特征

| 维度 | Claude | Gemini | OpenAI | Markdown |
|-----|--------|--------|--------|----------|
| **复杂度** | 中 | 中 | 高 | 低 |
| **平台绑定** | 强 | 强 | 强 | 无 |
| **功能完整性** | 高 | 中 | 高 | 低 |
| **上传复杂度** | 低 | 中 | 高 | N/A |
| **增强质量** | 优秀 | 良好 | 良好 | N/A |

### 选择建议

1. **使用 Claude Code** → 选择 `claude` 适配器
2. **使用 Google AI Studio** → 选择 `gemini` 适配器
3. **使用 ChatGPT Assistants** → 选择 `openai` 适配器
4. **通用文档导出** → 选择 `markdown` 适配器
5. **不确定平台** → 先用 `markdown`，后续可转换

### 架构优势

✅ **单一代码库**支持 4 个平台
✅ **统一接口**降低学习成本
✅ **平台隔离**便于维护和测试
✅ **易于扩展**添加新平台只需实现 `SkillAdaptor`
✅ **可选依赖**不使用的平台无需安装依赖
